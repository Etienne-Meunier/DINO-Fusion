Now the constraint we applied in our paper is focusing on bringing the profiles closer to the average density profile. Which is done with a constrained optimisation. We can see it works and mechanically respect the constraint but loose variability over the density

7.   
Applying more complex constraints requires us to revisit our algorithm : starting from what we do earlier we consider that h, which evaluate **constraint violation** is not differentiable and that we have a proximal operator instead that brings any profile on the valid set. 

This gives a new algorithm relying on variable splitting like Matthieu presented but with a different objective : we don't want the sample to strictly respect the constraint but to respect it in average, although using projection. 

This algorithm is going to alternate sampling, projection and ascent steps on the lagrangian multiplier. 

8.
Leveraging that we can formulate two different constraints : the first one is isotonic : the density should be monotonically increasing and we can rely on the isotonic projection to do that : now our profiles respect stratification while having variability 

9. 
The second constraint is more close to clustering, we employ an assignment algorithm namely hungarian algorithm to bring the profiles towars the centroids computed earlier with the right repartition. We can see the density profiles follow the cluster while density and salinity have variability.
